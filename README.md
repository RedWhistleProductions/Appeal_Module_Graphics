# Graphics

An Appeal module project.

Sprite-sheet animation commands and examples: [Animations](Docs/Animations.md).

## Development status

This repository was separated from the Appeal beta development tree. Its build and installer configuration will be modernized before the first standalone release.

Generated binaries and intermediate objects are intentionally excluded from version control.


## SDL2 OpenGL plugins

The SDL2 plugin is now named Appeal_SDL2_Legacy_OpenGL_Graphics. A separate Appeal_SDL2_Modern_OpenGL_Graphics project uses OpenGL 3.3 core shaders. See [backend selection and shader configuration](Docs/OpenGL_Backends.md).
