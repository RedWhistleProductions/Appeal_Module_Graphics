Using the Graphics module

Prefix each command with Graphics. Arguments above appear in the order the interpreter reads them. Quote strings containing spaces; use "" for an empty string. Commands and plugin features depend on the loaded Graphics plugin.

Add_Dynamic_Module Graphics Appeal_SDL2_Graphics
Graphics Add_Window Main "My Window" 800 600
Graphics Set_Window_Title Main Bananas
Graphics Set_Window_Title Main "Bananas and Apples"
Graphics Set_FPS 60
Graphics Wait_Until_Close Main
Graphics Close_All

Set_Window_Title changes the caption without recreating the window or changing its position or size. The SDL2 plugin ignores unknown window names.

Reading state

Graphics query commands publish state in shared globals rather than returning expression values. Run the query before reading the corresponding global. GUI state uses names beginning with Graphics.GUI.; window state uses Graphics.Window..

Graphics Window_Open Main
Set_Var_Global Is_Open Graphics.Window.Main.Open
Print Var Is_Open

For a script-controlled render loop, call Graphics Render and Graphics Update each frame, then query Window_Open again. Use Wait_Until_Close when no other script work needs to run while the window is open.
