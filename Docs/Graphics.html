Graphics Module

SDL2 windows support Alt+Enter (including keypad Enter) to toggle desktop fullscreen, in GUI or game input focus. Key repeats are ignored. Leaving fullscreen restores windowed geometry. Add_Full_Screen_Window starts with a smaller remembered window size for its first transition to windowed mode.

Appeal docsModule standardBasicAdvancedGlobals

Script functions provided by the Graphics module. Prefix each call with Graphics; arguments below are consumed in the listed order. Plugin support and behavior may vary.

Basic covers ordinary application and game operations. Advanced covers explicit setup, backend management, and tuning. This classification describes the current API; it does not certify that every backend yet provides the complete Basic-only game workflow required by the standard.

GUI sprite previews and selection

GUI_Image Name File Frame_Width Frame_Height Frame Span Size draws a square sprite preview over a checkerboard. File is relative to Graphics/Sprites; Frame is zero-based and row-major; Span counts adjacent horizontal frames (normally 1). Size is the preview width/height in pixels (1..4096). Invalid or missing images leave the checkerboard visible. Use within GUI_Begin / GUI_End_Window. GUI_Set_Selection_Value Name Value updates a combo/list index without invoking its callback; selected text refreshes when rendered.

Draw order

Set_Draw_Order Name Order sets an integer rendering order for an asset. Lower values render first. The default is 0; equal orders retain asset-name order. This is independent of position Z and works for alpha-blended 2D sprites.

Dockable editor workspace

The bundled ImGui build supports docking. Set_GUI_Editor_Mode True, after creating a window, enables a docked editor shell with a 1100x800 scene render target. It keeps GUI interaction available alongside the view and saves layout to Graphics/GUI/Editor_Layout.ini. Use GUI_Begin_Frame once per frame, followed by any number of GUI_Begin_Window Name / GUI_End_Window pairs. Unlike GUI_Begin, GUI_Begin_Window appends to the frame. The default panel names are Components, Editing View, and Editor Controls. GUI_Reset_Editor_Layout restores their initial arrangement.

GUI_Editor_Viewport Name X Y W H displays a region of the scene target, preserving its aspect ratio. GUI_Viewport_Value Name Field returns current viewport input after Render: X/Y are local source pixels, Left/Right are button states, Wheel is the wheel delta, and Hovered indicates interaction within the visible image. Input resets when the image is hidden, collapsed or not hovered. Origin_X/Origin_Y and Width/Height describe its displayed rectangle. False disables editor mode and restores ordinary scene rendering.

GUI item width

GUI_Set_Next_Item_Width Width sizes the next input widget. Positive values are pixels; negative values reserve that many pixels on the right of the available content region (minimum widget width 32 pixels). When followed by GUI_Combo, its popup is constrained to the same width, allowing a preview beside the selector to remain visible. GUI_Viewport_Value also accepts Middle for the hovered viewport middle-button state.

Tile source attributes

Sprite_Info File Frame_Width Frame_Height Frame Span Field reads source image information without requiring a Graphics window. File is relative to Graphics/Sprites. Folder returns the containing folder for an existing image. Width/Height return image dimensions. Opaque returns 1 if every pixel in the selected frame span has alpha 255, 0 if it contains transparency, and -1 if it cannot be analyzed. Source alpha is cached and refreshed when the file timestamp changes. GUI_Checkbox_Value and GUI_Checkbox_Changed now also return expression results while continuing to publish their existing globals.

Pixel-aligned sprites and editor state

Paste_Rect Name Left Top Right Bottom places a 2D sprite using bounds snapped down to integer pixels. Shared tile boundaries resolve to the same edge, preventing gaps and repeated alpha blending on fractional thumbnail scales. Normal Paste restores ordinary scale-based placement. GUI_Set_Slider_Int_Value Name Value updates an existing slider without firing its callback. GUI_Set_Next_Window_Scroll Y sets the next GUI window's vertical scroll position.

Playlist Editor controls

GUI_Music_Picker_Recursive Name Enabled enables a cached recursive library for a named GUI_Music_Picker. Drag payloads use music-root-relative paths in this mode. The Rescan music button refreshes the inventory. The default nonrecursive picker is unchanged.

GUI_Playlist_Save Name returns 1 when the named playlist file is written successfully, otherwise 0. It can be used as an Appeal expression. GUI_Playlist edits save automatically and invoke the registered callback. Empty lists accept song drops and existing entries can be dragged to the append target.

Editor grid drag and drop

GUI_Viewport_Grid Name Columns Rows enables tile-map drag/drop for a GUI_Editor_Viewport; use zero dimensions to disable. GUI_Viewport_Value Name Drop_Cell returns the delivered destination or -1; Drop_Source returns its source cell, or -1 for a map preview. Values reset each GUI frame. Scripts decide whether to move, swap, or assign.

GUI_Map_Preview Name Target X Y Width Height Size shows a square thumbnail cropped from the editor canvas and drags to the named grid viewport. The editor canvas is 1400 by 800; Level Editor reserves X=1120 onward for preview rendering. GUI_Viewport_Value also exposes preview Origin_X, Origin_Y, Width, and Height.

Closable GUI windows

GUI_Begin_Window, GUI_Begin, and GUI_Begin_Fullscreen windows have native title-bar close controls. Closed windows skip their contents until reopened. Editor mode provides a Windows menu for reopening panels and restoring all windows.

GUI_Set_Window_Open Name Open sets a window's visibility without invoking callbacks. GUI_Set_Window_Functions Name Close_Function Open_Function registers digital script callbacks for user closure and reopening from the Windows menu. Use None for an unused callback. GUI_Reset_Editor_Layout also restores closed windows and invokes their open callbacks.
